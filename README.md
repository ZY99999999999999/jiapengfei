# 蒙古族纹样数字化平台

以蒙古族传统纹样为核心的数字化展示与互动创作平台。项目从符号学的语义、语构与语用三个维度组织内容，让纹样不仅被观看，也能够被理解、重组与应用。

## 核心模块

- **纹样探索**：按几何、植物、动物、生活器物等类别浏览纹样及其文化寓意。
- **指尖纹韵**：结合手势识别与粒子视觉，以身体交互感受纹样的节奏和能量变化。
- **纹样创作**：通过参数控制、画线与素材组合，生成新的纹样表达。
- **智慧推荐**：以浏览器本地的趣味性特征分析生成纹样推荐，并明确体验边界与隐私说明。
- **首页导览**：介绍平台方法、功能入口与蒙古族五色体系。

## 设计方法

平台采用“双轨转化”思路：一条路径通过形状文法重组纹样形式，另一条路径通过文化语义映射保持寓意连续性。界面以深蓝、金、红、白、青绿为主要色彩，并通过统一按钮、焦点状态、触控尺寸和响应式布局适配电脑、平板与手机。

## 本地运行

请使用本地服务器访问，不要直接双击 HTML 文件，以免浏览器限制资源读取。

```bash
node server.js
```

启动后打开：`http://localhost:8766/index.html`

Windows 用户也可以双击 `start.bat`。

## 项目结构

```text
index.html          首页与平台导览
explorer.html       纹样探索
fingerweave.html    指尖纹韵
creator.html        纹样创作
recommend.html      智慧推荐
platform-ui.css     跨页面设计系统与响应式规则
server.js           本地静态服务与纹样数据接口
pattern_images/     纹样图像素材
wenyang_svg/        SVG 纹样素材
data/               平台数据
```

## 技术说明

项目以原生 HTML、CSS、JavaScript 为主，使用 Three.js、MediaPipe Hands、face-api.js 等前端能力。推荐页的图像分析在浏览器本地完成，平台服务器不接收用户照片。

## 展示建议

- 推荐使用 Chrome 或 Edge 最新版本。
- 摄像头功能需要浏览器授权，并应通过 `localhost` 或 HTTPS 访问。
- 首次打开含模型的页面时，需要等待依赖资源加载完成。
