## 现在可以体验

- 自动路线从高空下降并贴地穿行；「自由遨游」可脱离路线，按住鼠标拖拽才会转向。点「停止滑翔」或按空格可明确停住，滚轮只改变下一次滑翔的速度，不会悄悄重新启动。WASD/方向键移动，Q/E 升降，Esc 退出特写，R 回到起点。
- 点击场景中的动物，或打开「定位纹样」选马、牛、羊、山羊、骆驼等形体，镜头会移近并居中观察。动物特写时五座火山暂时隐藏，避免亮峰穿过动物轮廓；退出后恢复五峰，并平滑返回原先的遨游位置。特写内可重播动作或退出。动物视频只作为本地逐帧解码源，不会把视频平面贴入三维空间；视频帧被采样为带深度、具有纹样字形的粒子点阵。牛的低头吃草、马的奔跑及其他动物运动来自用户提供的视频。视频载入失败时回退到静态图粒子动作。
- 不点击时，五畜也有按物种区分的轻量步态、身体起伏和头部动作。镜头从前方近距离掠过时，动物会短暂转头回应，再回到原姿态；这是保留原画粒子轮廓的 2.5D 程序动画，不是完整骨骼三维动物。此项已通过脚本语法与本地 HTTP 资源检查，真实浏览器视觉节奏仍需复验。
- 用户提供的红、青、金莲形图被采样为彩色粒子太阳。草地使用本项目绘制的连续卷叶枝蔓纹样转译；云层使用相连云头与回旋云涡的卷云单元；环境与动物的近景微粒子使用平台纹样图集。颜色可切换为环境色或近单色扫描风格。

## 技术边界

场景用项目已有的 Three.js ES Module、`BufferGeometry` 和自定义点精灵着色器构成真正有前后关系的点云环境；动物视频特写是 2.5D 粒子形体，并非可绕到背面观看的完整三维雕塑。用户提供的动物图及视频、太阳图均是原型参考，不应被误述为经过考据的传统纹样。原型不是乌兰哈达真实地形扫描，也不是参考视频画面的复制。

红崖台地参考的是乌兰察布四子王旗的沉积红层地貌，并非玄武岩或乌兰哈达火山本体；本场景是两种地域意象的艺术化并置，不表示它们在真实地理上相邻。地貌核查参考：[中国网《乌兰察布：“阴山十景”入画来》](https://grassland.china.com.cn/2022-05/30/content_41986337.html)。

五座火山目前是**独立原型中的艺术化三维重建**，不是五张原画的逐像素、全角度等同复原：原图未提供背面与三维数据，侧后部为推演；02–05 的装饰形体仍需继续打磨相似度、轮廓与遮挡。五座设计图也不是五座真实火山的地貌照片；此处只借用景区大致南北/东西关系做场景构图，不应当作精准卫星复原。

创意共创入口、作品命名、放飞/融入选项、五峰目的地、飞行进度与完成提示已接入完整粒子世界。尚待核对五张设计图的逐峰形态细节，并在不同显卡上检查长时间帧率、在用户设备上复验真实摄像头手势。

本地浏览器已检查动物特写、动作播放、太阳、停止/继续和布局。不同显卡的长期帧率、摄像头真实手势识别以及不同桌面尺寸仍需用户设备上复验。若本地服务未运行，请先启动项目原有的本地服务；不要直接用 `file://` 打开，以免媒体和模块受浏览器安全限制。
